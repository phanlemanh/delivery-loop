# Mở phiên ở Mac Studio

Chủ kho làm hai bước rồi dán khối lời dưới đây vào một phiên Claude Code MỚI có thư mục là kho `delivery-loop`.

**Bước 1 — kéo kho về (một lần):**

```bash
cd ~/dev && git clone https://github.com/phanlemanh/delivery-loop.git && cd delivery-loop && git remote add kit-cu https://github.com/phanlemanh/acceptance-gate-kit.git && git fetch kit-cu --tags && git switch chuyen-nha
```

**Bước 2 — mở phiên mới**, thư mục `~/dev/delivery-loop`, rồi dán:

---

Tôi là chủ kho. Đây là kho `delivery-loop`, kế nhiệm của `acceptance-gate-kit`, đang ở giữa đợt chuyển nhà. Phiên MacBook
Pro đã dựng nền và bàn giao cho máy này làm chính từ đây.

Đọc theo thứ tự, trước mọi việc khác:
1. `migration/BOI-CANH.md` — ai đã quyết gì, luật của đợt, bẫy đã dẫm.
2. `migration/KE-HOACH.md` — kế hoạch đầy đủ; mục 12 và 13 là bản đang hiệu lực.
3. `CLAUDE.md` của kho — luật của kit vẫn áp nguyên.

Rồi trình tôi một tin: bản đồ **đã xong · đang dở · kế**, và đúng MỘT quyết định cần tôi kèm khuyến nghị. Đừng mở vòng nào
trước khi tôi gọi tên. Kho cũ `acceptance-gate-kit` vẫn là nguồn duy nhất của sản phẩm tới ngày cắt sang.
